# 执行计划

## 概述

加载计划，批判性审阅，执行所有任务，完成后报告。

**开始时宣布：**“我正在使用 executing-plans 技能来实现这份计划。”

**注意：**告诉你的人工协作者，在有子智能体（Claude Code、Codex CLI、Codex App、Copilot CLI 和 Gemini CLI 都符合条件）可用时，Superpowers 的效果会好得多；参见 `../using-superpowers/references/` 中按平台划分的工具参考。如果有子智能体可用，使用 superpowers:subagent-driven-development，而不是本技能。

## 流程

### 第 1 步：加载并审阅计划
1. 确保工作区隔离：使用 superpowers:using-git-worktrees 创建一个工作区，或验证当前工作区已经隔离
2. 阅读计划文件
3. 批判性审阅——找出计划中的问题或疑虑
4. 如果有疑虑：在开始前向你的人工协作者提出
5. 如果没有疑虑：为计划项目创建待办事项并继续

### 第 2 步：执行任务

对每项任务：
1. 标记为进行中
2. 严格按照计划中的每个步骤执行（计划包含细粒度步骤）
3. 按要求运行验证
4. 标记为已完成

### 第 3 步：完成开发

所有任务完成并验证后：
- 宣布：“我正在使用 finishing-a-development-branch 技能来完成这项工作。”
- **必需的子技能：**使用 superpowers:finishing-a-development-branch
- 遵循该技能来验证测试、展示选项并执行所选方案

## 何时停止并寻求帮助

出现以下情况时，**立即停止执行：**
- 遇到阻塞（缺少依赖、测试失败、指令不清楚）
- 计划存在阻止开始的关键缺口
- 你不理解某条指令
- 验证反复失败

请求澄清，而不是猜测。

## 何时回到前面的步骤

在以下情况回到审阅步骤（第 1 步）：
- 协作者根据你的反馈更新了计划
- 根本性的方案需要重新思考

不要强行越过阻塞继续——停下来寻求帮助。

## 记住
- 先批判性审阅计划
- 严格遵循计划步骤
- 不跳过验证
- 计划要求调用哪些技能，就引用哪些技能
- 遇到阻塞就停止，不要猜测
- 未经用户明确同意，绝不要在 main/master 分支上开始实现

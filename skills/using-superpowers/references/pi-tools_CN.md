# Pi 工具映射

技能以动作（“调度子代理”“创建待办事项”“读取文件”）进行描述。在 Pi 上，这些动作对应以下工具。

| 技能请求的动作 | Pi 等价方式 |
| --- | --- |
| 调度子代理（`Subagent (general-purpose):` 模板） | 如果已安装，可使用 `pi-subagents` 提供的 `subagent` 等子代理工具 |
| 任务跟踪（“创建待办事项”“标记完成”） | 如果已安装，使用已安装的 todo/任务工具；否则在计划或 `TODO.md` 中跟踪任务 |

## 子代理

Pi 核心不附带标准子代理工具。`pi-subagents` 软件包是一个功能完善的可选配套组件，在可用时提供 `subagent` 工具，支持单代理、链式、并行、异步、分叉上下文以及恢复/状态工作流。如果没有可用的子代理工具，不要臆造 `Task` 调用；应在当前会话中按顺序执行，或说明未安装可选的子代理能力。

## 任务列表

Pi 核心不附带标准任务列表工具。如果安装了 todo/任务扩展，使用其文档化的工具。否则使用 Superpowers 计划文件、Markdown 中的清单，或仓库内的 `TODO.md` 进行任务跟踪。较旧的 Superpowers 文档可能会提到 `TodoWrite`；将其视为上述任务跟踪动作。
